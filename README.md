# 🚦 Smart Traffic Surveillance System  
**AI-Based Vehicle Detection & Counting using YOLOv8, OpenCV & Tkinter**

## 📌 Overview  
This project is a real-time **vehicle detection and counting system** built using deep learning and computer vision.  
It detects vehicles (cars, buses, trucks, motorcycles), tracks them across frames, and counts traffic flow based on direction using a professional Tkinter dashboard.

The system is designed as a **smart-city traffic monitoring solution** and is suitable for academic projects and real-world surveillance prototypes.

---

## 🧠 Features  
- ✅ Real-time vehicle detection using YOLOv8  
- ✅ Multi-class detection (Car, Bus, Truck, Motorcycle)  
- ✅ Direction-based vehicle counting (Up / Down)  
- ✅ Professional Tkinter GUI dashboard  
- ✅ CSV export for traffic reports  
- ✅ Snapshot capture  
- ✅ Live event logs  
- ✅ Visual alert when vehicles cross detection line
